# Jeevandhara Experimental Tomato Model

## Contents
- tomato_mobilenet_v3_small.onnx: exported eight-class classifier
- model_metadata.json: input preprocessing, output class order, evaluation and limitations
- test_metrics.json / confusion_matrix.csv: included if generated by training

## Important
This is an experimental model trained and evaluated on curated tomato leaf images.
The reported 96.73% held-out accuracy does not establish accuracy on farm photographs.
Do not present its predictions as confirmed diagnoses. Unknown and unsupported cases
need safe handling in the application.

Dataset and model redistribution rights have not been fully verified. Do not publish
or redistribute the model package until the relevant rights are clarified.
